# FBACスクリプト

このディレクトリには、FBACアバターの動作には直接関係のない外部スクリプトが格納されています。
利用可能なスクリプトは次のとおりです。

## ビルドスクリプト

このスクリプトはFigura Blue Archive Crafters（FBAC）アバターのソースファイルを、ゲーム内で実際に使用可能なデータに変換(ビルド)するコマンドラインツールです。

詳しくはビルドスクリプトの[README](./build/README_jp.md)を参照してください。

## README生成スクリプト

このスクリプトは本レポジトリ（のREADMEのマークダウンドキュメント および 配布データに含めるREADMEテキストファイルをテンプレートから作成するツールです。

詳しくはREADME生成スクリプトの[README](./readme_generate/README_jp.md)を参照してください。
