# アバター作成の手順書

本ドキュメントでは、アバターの作成を行う一連の手順とTodoを記します。

新しいキャラクターの作成と、既存のキャラクターに対する新規衣装の作成手順を記します。

## アバターの作成前

アバターの作成前に行う作業の手順は次のとおりです。

1. Issueを作成する。
   - 新規キャラクターの作成は「新キャラクター」のテンプレートを、新規衣装の作成は「新衣装」のテンプレートでIssueを作成する。
   - テンプレート内のプレースホルダー（`${...}`）は適切な内容に置き換える。
2. アバター作成状況([`creation_status.json`](scripts/readme_generate/creation_status.json))を更新する。
   - 新規キャラクターの場合は`planned`の配列に以下を追加する。

     ```json
        {
            "character_name": {
                "first_name": {
                    "en": "${STUDENT_FIRST_NAME}",
                    "jp": "${生徒の名前}"
                    },
            "last_name": {
                    "en": "${STUDENT_LAST_NAME}",
                    "jp": "${生徒の名字}"
                }
            },
            "costume_name": null,
            "issue_number": ${手順1.で作成したIssue番号}
        }
     ```

   - 新規衣装の場合は`planned`の配列に以下を追加する。

     ```json
        {
            "character_name": {
                "first_name": {
                    "en": "${STUDENT_FIRST_NAME}",
                    "jp": "${生徒の名前}"
                    },
            "last_name": {
                    "en": "${STUDENT_LAST_NAME}",
                    "jp": "${生徒の名字}"
                }
            },
            "costume_name": {
                "en": "${COSTUME_NAME}",
                "jp": "${衣装名}"
            },
            "issue_number": ${手順1.で作成したIssue番号}
        }
     ```

## アバター作成に必要なもの

アバターの制作に必要なリソースは次のとおりです。

- 参考にする公式のキャラクター立ち絵（画像）
- 生徒の基本情報
  - 名字・名前（日本語/英語）
  - 部活名（日本語/英語）
  - 誕生日
  - 攻撃属性
- 参考にする固有武器の画像
- Exスキルの名前（日本語/英語）
- 参考にするExスキルカットイン（動画）

上記リソースの入手先は次のとおりです。

- 公式ゲームから
- Wikiから（Exスキルカットイン以外）
  - 日本語Wiki ... <https://bluearchive.wikiru.jp/>
  - 英語Wiki ... <https://bluearchive.wiki/>
- [YouTube](https://www.youtube.com/)などから（Exスキルカットイン）
  - 誰かがExスキルカットインの動画をアップロードしているはず。
- 公式資料集（オフィシャルアートワークス）から
  - ゲームだとあまり見えない角度や小物類などの設定などを確認できる。

## アバター作成手順

### アバター作成概要

アバター/衣装の作成は、以下の5フェーズで行います。

1. フェーズ1 ... キャラクターモデルの作成
   - アバターのメタ情報（アバター名、キャラクター名、誕生日、部活名）を設定
   - メインモデルの作成
   - メインモデルに使用するテクスチャの作成
   - 揺れもの（長い髪、アクセサリー）などのパラメーターを設定
   - キャラクター固有のギミックの作成
   - 頭ブロックモデルの調整
2. フェーズ2 ... 固有武器モデルの作成
   - 固有武器のモデルを作成
   - 固有武器モデルのテクスチャの作成
   - 固有武器の挙動（武器のしまい方、武器の構え方、発砲音）の設定
   - 固有武器の固有ギミックの作成
3. フェーズ3 ... アバターサムネイルの作成
   - 参考にする公式立ち絵と同じポージングのキャラクター立ち絵を作成
   - 作成した立ち絵をアバターサムネイル用にトリミング・調整
   - サムネイルのフレームカラー（キャラクターの攻撃属性）の設定
4. フェーズ4 ... Exスキルカットインの作成（複数ある場合は全て作成）
   - Exスキルアニメーションの作成
   - Exスキルカットインのカメラワークを作成
   - Exスキルカットインの視覚的演出（パーティクル、UI演出など）を作成
   - Exスキルカットインの効果音を作成
5. フェーズ5 ... 最後の仕上げ
   - 防具を表示したときの見た目の調整
   - 死亡アニメーションの見た目の調整
   - 吹き出しエモート再生時の表情の設定

新規衣装の作成時は、フェーズ2がスキップできる場合があります。

### アバター作成詳細

アバターの作成を行う手順は次のとおりです。

1. アバター作成状況([`creation_status.json`](scripts/readme_generate/creation_status.json))内の対象キャラクターのエントリーを`planned`/`requested`から`in_progress`に移動する。
   - 変更は`main`にプッシュする。
2. 作業用のブランチを`main`から作成する。
3. アバターの雛形をコピーする。
   - コピー元 ... `src/avatars/00a_Base`
     - 新規衣装の場合は同じキャラクターの別衣装からのコピーも可
   - コピー先 ... `src/avatars/${FBAC_ID}_${キャラクター名}` もしくは `src/avatars/${FBAC_ID}_${キャラクター名}_${衣装名}`
     - キャラクター名と衣装名は頭文字を大文字にして、英語で記述する。
4. アバターのメタ情報を設定する。
   - アバター名 ... `avatar_json_config.json`内の`placeholders`内に英語で設定する。
     頭文字は大文字にする。
     - `first_name` ... 生徒の名前
     - `last_name` ... 生徒の名字
     -　`costume_name` ... 衣装の名前
   - 誕生日 ... `blue_archive_character.lua`内の`BlueArchiveCharacter.basic.birth`に生徒の誕生日を設定する。
   - キャラクター名・所属部活名・（Exスキルの名前） ... [FBAC_Localesリポジトリ](https://github.com/Gakuto1112/FBAC_Locales)内に`src/avatars/${FBAC_ID}_${キャラクター名}` もしくは `src/avatars/${FBAC_ID}_${キャラクター名}_${衣装名}`のディレクトリを作成し、その中に翻訳キー用のjsonファイルを作成する。
     - `en_us.json` ... 英語（US）、`ja_jp.json` ... 日本語
       - `character.first_name` ... 生徒の名前
       - `character.last_name` ... 生徒の名字
       - `character.club_name` ... 所属する部活名
       - `ex_skill.primary_name` ... Exスキルの名前
       - `ex_skill.secondary_name` ... サブExスキルの名前（存在する場合）
